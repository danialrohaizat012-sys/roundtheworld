# Astra V46.1 — Flutter-style UI Foundation

Built from V46 Home UI.

This is a visual/interaction foundation, not a Flutter rewrite:
- Material-inspired mobile surfaces with Astra navy/gold identity.
- Floating rounded NavigationBar-style bottom navigation.
- Native-feeling buttons, pressed states, cards and ListTile-style Adventure rows.
- Filled structured text fields/selects with consistent focus treatment.
- Consistent radii, elevation and mobile spacing tokens.
- V46 cinematic Home retained.
- Existing Firebase, Journey, Adventure, World, sequence, Delete/Restore and structured-form logic preserved.
